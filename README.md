# Space Invaders Retro

PWA vertical per a mòbil, creada amb React i Vite.

## Requisits
- Node.js LTS
- Visual Studio Code (recomanat)

## Instal·lació
Obre PowerShell dins d'aquesta carpeta i executa:

```bash
npm install
npm run dev
```

Obre l'adreça local que mostra Vite (normalment http://localhost:5173).

## Comprovació de producció
```bash
npm run build
npm run preview
```

## Controls
- Fletxa esquerra / A: moure a l'esquerra
- Fletxa dreta / D: moure a la dreta
- Espai: disparar
- Mòbil: botons tàctils de la pantalla

El rècord es desa al navegador mitjançant localStorage.
